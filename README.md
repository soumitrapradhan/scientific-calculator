# Scientific Calculator

A responsive scientific calculator built with plain HTML, CSS and JavaScript, with an animated particle background and a light/dark theme.

**Live demo:** https://YOUR-USERNAME.github.io/scientific-calculator/

## Features
- DEG / RAD modes
- sin, cos, tan, inverse trig, sinh, cosh, tanh
- log, ln, √, ∛, x^y, n!, nPr, nCr, GCD, LCM
- Memory keys (MC, MR, M+, M-) and Ans
- Calculation history
- Light / dark theme toggle (remembers your choice)
- Keyboard support (digits, operators, Enter, Backspace, Esc)
- Animated background (respects reduced-motion settings)

## Run locally
Open `index.html` in any browser. No build step needed.
